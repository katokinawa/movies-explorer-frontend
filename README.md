# Обозреватель фильмов

Веб-приложение для поиска фильмов по запросу с возможностью сохранения избранных фильмов в личном каталоге.

## Технологии

- React 18
- React Router

## Функциональность

- Поиск фильмов по названию
- Фильтрация по длительности
- Сохранение избранных фильмов
- Редактирование профиля пользователя
- Авторизация и регистрация

## Установка и запуск

### Требования

- Node.js 18.x или выше
- npm или yarn
- Backend API: [movies-explorer-api](https://github.com/katokinawa/movies-explorer-api)

### Шаги установки

1. Клонировать репозиторий:
```bash
git clone https://github.com/katokinawa/movies-explorer-frontend.git
```

2. Перейти в директорию проекта:
```bash
cd movies-explorer-frontend
```

3. Установить зависимости:
```bash
npm install
```

4. Запустить проект:
```bash
npm start
```

Приложение откроется в браузере по адресу `http://localhost:3000`

5. Для сборки production версии:
```bash
npm run build
```
